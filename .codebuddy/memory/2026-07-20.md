## 启动前端开发服务器
- 前端项目位于 `d:\LearnJava\Fish-Agent\frontend`，使用 pnpm + Vite + Vue3。
- 启动命令: `pnpm dev`，默认地址 http://localhost:5173。

### 关键排错记录（Windows 环境坑）
- 首次启动报 `ERR_MODULE_NOT_FOUND: Cannot find package 'picomatch'`。
- 直接 `pnpm install` 在不同文件处反复报 `UNKNOWN: unknown error, open '...package.json'`（picomatch / highlight.js / dompurify 轮流失败）。
- 根因：pnpm 默认 `.pnpm/` 嵌套结构 + Windows 文件锁/Defender 实时扫描导致硬链接提取竞态。
- 解决方案：删除 `node_modules` 后改用 `pnpm install --node-linker=hoisted`（扁平化结构），4 秒完成安装无错误。
- 之后 `pnpm dev` 可正常启动。
- 后续若再遇同类问题，直接用 `--node-linker=hoisted` 重装即可。
